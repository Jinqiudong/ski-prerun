# Animals

- `3d/<name>.glb` — the rigged animals with a walk cycle that roam the resort tiles on the Colorado map
  (`src/start/resort-tiles.js`), built by `tools/build_animals.py`.
- `<name>.png` — the owner's painted originals (cut from their wildlife sheet), the reference the 3D
  animals were made from. Not loaded by the game.
